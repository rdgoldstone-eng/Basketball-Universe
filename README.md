# Basketballverse v0.95.07
## Portrait Display Fix

**CURRENT BUILD: v0.95.07**

Built directly from v0.95.06.

v0.95.06 did contain all eight portrait files, but an older portrait renderer was
bypassing the new universal portrait registry. This build fixes the display path so
the bundled images are actually used by the player portrait HTML renderer.

Bundled portraits:
- Julius Erving
- Bill Walton
- Pete Maravich
- Walt Frazier
- Paul Silas
- Bernard King
- Jack Sikma
- Marques Johnson

The original `PORTRAIT_SOURCES.md` licensing/source manifest remains included.

This is a display fix only; no additional portrait claims were added.

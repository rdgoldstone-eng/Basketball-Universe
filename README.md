# Basketballverse v0.91.64 — Character Portrait Foundation

Created career characters now support a persistent portrait identity.

- Describe Your Appearance field
- Era-aware portrait prompt generation
- Prepare AI Portrait stores a secure-generation-ready prompt without embedding an API key
- Upload Portrait works now
- Default portrait fallback
- Portrait stays attached to the same Career Person across future Player → Coach → GM chapters

Era styling automatically changes for 1970s, 1980s, 1990s, 2000s, 2010s, and modern careers.

The actual one-click AI generation connection will be added later with a secure backend rather than exposing an API key in the GitHub Pages client.

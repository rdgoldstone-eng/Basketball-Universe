# Basketballverse — v0.97.42

## Current Build

**v0.97.42 · Player Name + Portrait Repair**

## Changes in v0.97.42

- Rejects malformed names that contain `undefined`, `null`, or `defined` anywhere in the name.
- Prevents new malformed prospects from entering the league through the draft.
- Repairs affected players already stored in an existing browser save.
- Recovers historical names from the draft-class identity or stored portrait key whenever possible.
- Updates matching award, season-history, draft-history, news, and newspaper records after a name repair.
- Resolves newspaper MVP, Rookie of the Year, and first-pick portraits from active players, retired players in draft classes, and stored portrait keys.
- Keeps uploaded portrait URLs and explicit portrait keys ahead of name-based filename guesses.
- Forces a completed draft to advance to Re-signings even when an older transition helper returns without changing the offseason phase.
- Updates the home-page version, update checker, and persistent watermark to v0.97.42.

## Existing Save Repair

Open the affected universe normally. Basketballverse checks the roster and current draft class after loading. If it finds a malformed name, it repairs the player and the connected awards, draft results, news, and newspaper entries, then saves the corrected universe.

## Portrait Requirements

Historical portraits still require the matching file in the repository's `portraits/` folder. The preferred filename comes from the player's stored `portraitKey`; otherwise Basketballverse uses the normalized player name, such as `george_mikan.webp`.

Fictional players generated by the simulation do not have uploaded historical photos. They continue to use the initials fallback until the planned headshot-generator system supplies an image.

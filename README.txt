Basketballverse
v0.91.17 · Multi-Asset Trades & Pick Projection

TRADE MACHINE
- Explicitly supports multi-player / multi-pick packages.
- Select any number of players and draft picks on BOTH sides using the checkboxes.
- A notice now explains that every checked asset is included in the trade.
- Selected trade rows are visually marked.

DRAFT PICK VALUES
First-round picks are no longer all valued the same.

Basketballverse projects the ORIGINAL team's likely draft position using:
- current record
- current team power
- how far into the season the league is
- contender / rebuilding direction
- how far in the future the pick is

Pick rows now show an estimated range, for example:
2029 Round 1
Proj. #3–7 via Seattle · Trade value 40

VALUE TIERS
- projected top 3 picks are premium assets
- projected top 5 / top 10 picks remain very valuable
- mid-firsts are worth less
- late firsts are worth considerably less
- second-round picks also scale from early to late
- distant picks receive an uncertainty discount, but retain projected-position differences

TRADE FINDER
Draft picks inside Trade Finder offers use the same projected slot and value model.

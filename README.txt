v0.91.33 · Draft Selection Cleanup

DRAFT ROOM
- Removed the redundant Prospect Board presentation from Draft Night.
- The card is now called Make Your Selection.
- When your team is on the clock, that one section shows the available players
  with the same useful information:
  Name · Position · Age · OVR estimate · POT estimate · College
- Each player has the Draft button directly beside him.
- The duplicate Make Your Selection panel that previously appeared elsewhere on
  the page is removed.
- When another team is on the clock, the section simply says whose pick it is.
- Before the draft / after completion, it shows a short status instead of a
  40-player board.

The full prospect class still belongs in Scouting, where it can be reviewed
before Draft Night.

Retains all systems from v0.91.32.
